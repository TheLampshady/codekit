# Decision Log

What was decided and why, one entry per shipped ticket or spec, newest first, for reference when someone asks why something was built a certain way.

**AI-extracted, and it may be wrong.** The codekit update writes each entry after merge from the ticket's spec: the documents on its Linear issue, or its spec folder in the repo. The linked source is the record: check it before relying on an entry. Entries are never edited, and a later decision says which earlier one it replaces.
